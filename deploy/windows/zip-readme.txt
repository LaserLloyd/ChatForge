ChatForge for Windows
=====================

1. Right-click this zip, choose "Extract All...", and open the folder it makes.
2. Double-click "Install ChatForge".
   (If Windows says "Windows protected your PC", choose More info, then Run anyway:
   the file is not signed yet. The installer is plain text; open it in Notepad to read it.)
3. When ChatForge opens, click "Set up local AI".

What the installer does: it needs no administrator rights and installs for your user only.
It sets up Python and the libraries ChatForge needs (about 200 MB downloaded the first time),
adds Start menu and desktop shortcuts, and asks once whether ChatForge should start when you
sign in to Windows. Run "Install ChatForge" again any time to upgrade.

To remove it: double-click "Uninstall ChatForge". Your settings, chats and downloaded models are
kept unless you run  "Uninstall ChatForge.bat --purge"  from a command prompt, or answer Y when asked.

Details and options: deploy\windows\README.md in the project, or https://github.com/LaserLloyd/ChatForge
